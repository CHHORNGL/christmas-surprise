# Christmas Surprise 🎄

A cozy, romantic, kawaii Christmas surprise website built with React + Vite + CSS.

## Edit the Recipient Name & Personalized Message

Open [`src/christmasMessage.js`](src/christmasMessage.js) to edit `RECIPIENT_NAME`, the first-screen greeting, or the personalized Christmas letter in one place.

## Local Development

```bash
npm install
npm run dev
```

## Lint & Production Build

```bash
npm run lint
npm run build
```

## Deploy to Vercel

1. Push this project to a GitHub repository.
2. Import the repository at [vercel.com](https://vercel.com).
3. Vercel uses Vite automatically (`npm run build` → `dist`, configured in `vercel.json`).
4. Click **Deploy** to get a shareable public URL.
